# BigAmountService — Микросервис для обработки больших сумм

## 📍 Расположение файла плана
Файл этапов разработки находится в файле:  
**`BigAmountService/PLAN.md`** (называемый "файл плана" или "файл этапов").
Файл плана используй когда идет речь про планы или этапы.

---

## 🎯 Цель сервиса
Создать микросервис на **.NET 10**, который:
подключается к тестовой сети (например, Sepolia), подписывается на события (Events) смарт-контракта ERC-20, фильтрует транзакции крупнее определенной суммы и складывает их в PostgreSQL с использованием Nethereum. 
---

## 🛠 Используемые технологии и стек

### 1. Язык и фреймворк
- **.NET 10**.
- Язык: **C#**.
- Архитектура: **Микросервис** (ASP.NET Core Minimal API или классический контроллерный подход, в зависимости от предпочтений, но с фокусом на фоновую задачу).

### 2. Блокчейн и Web3
- Сеть: **Sepolia Testnet**.
- Библиотека: **Nethereum** (основной инструмент для взаимодействия с Ethereum через RPC).
- Задачи Nethereum:
  - Подключение к узлу (Node) через HTTP/WebSocket (например, через публичный RPC Sepolia или свой нод).
  - Создание фильтра событий (`EventFilter`) для отслеживания события `Transfer` из ERC-20 контракта.
  - Декодирование параметров события (от кого, кому, какая сумма).

### 3. Данные и хранение
- База данных: **PostgreSQL**.
- ORM: **Entity Framework Core** (для миграций, работы с моделями и DbContext).
- Хранилище конфигурации: `appsettings.json` или переменные окружения (для подключения к БД, RPC URL, адреса контракта).

### 4. Фоновая обработка
- Тип сервиса: **BackgroundService** (`IHostedService` в .NET), который запускается при старте приложения и работает непрерывно, слушая новые блоки/события.

## 📂 Структура папок проекта BigAmountService

### Основные папки:

- **`Controllers/`** - Контроллеры API (например, InfoController.cs)
- **`Interfaces/`** - Интерфейсы сервисов (например, IEthereumService.cs)
- **`Models/`** - Модели данных (например, BigAmountSettings.cs)
- **`Services/`** - Сервисы и бизнес-логика (например, EthereumService.cs)
- **`Properties/`** - Свойства проекта (launchSettings.json)
